A.R.I Kalender

Datenschutzerklärung

Stand: 4. September 2026

A.R.I ist ein persönliches Assistenz-Programm, das ausschließlich lokal auf dem Rechner seines einen Entwicklers und Nutzers läuft. Diese Erklärung beschreibt, wie die Google-Kalender-Anbindung dieses Programms mit Daten umgeht.

1 Konto

Angefragte Berechtigung: calendar.events

Termine im primären Kalender ansehen und anlegen.

Welche Daten gelesen werden

Über die Google Calendar API werden ausschließlich Titel, Start-/Endzeit und Ort der Termine im primären Kalender des Nutzers abgerufen — auf Zuruf legt A.R.I nach demselben Muster neue Termine an.

Wie die Daten verwendet werden

Einzig, um anstehende Termine im eigenen Dashboard des Nutzers anzuzeigen und um neue Termine auf ausdrücklichen Wunsch einzutragen. Es findet keine weitere Auswertung statt.

Wo die Daten gespeichert werden

  • Der Zugangs-Token liegt ausschließlich lokal auf dem eigenen Rechner des Nutzers.
  • Kalenderdaten selbst werden nicht dauerhaft gespeichert, sondern bei jedem Abruf neu von Google geladen.
  • Nichts wird an einen Server eines Drittanbieters, eine Cloud oder einen Analyse-/Werbedienst übertragen.

Weitergabe an Dritte

Findet nicht statt. Es gibt keine anderen Nutzer, keinen Verkauf, keine Analyse- oder Werbe-Integrationen.

Zugriff widerrufen

Der Zugriff kann jederzeit über die Google-Kontoberechtigungen entzogen werden. Der lokal gespeicherte Zugangs-Token wird dabei ungültig und kann zusätzlich manuell vom Rechner des Nutzers gelöscht werden.
